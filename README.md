# Salesforce Data 360 Interactive Workshop

![License](https://img.shields.io/badge/License-GPLv3-green?style=flat-square)

Una guía interactiva paso a paso diseñada para facilitar el aprendizaje y la ejecución de talleres sobre **Salesforce Data 360**. Este proyecto incluye instrucciones detalladas, flujos visuales y guías interactivas para la configuración e implementación de casos de uso prácticos.

🌐 **Demo en Vivo / Sitio Publicado:** https://salesforce-data360-workshop-a956d38f5270.herokuapp.com/

---

## 🚀 Contenido del Taller

El taller está estructurado en módulos interactivos que cubren el ciclo completo de trabajo en Salesforce Data 360:

| Módulo | Nombre del Ejercicio | Descripción / Alcance |
| :--- | :--- | :--- |
| **Ejercicio 3** | Ingesta y Modelado de Datos | Configuración de Data Streams, Mapeo de Objetos DMO/DSO y reglas de normalización. |
| **Ejercicio 4** | Unificación y Enriquecimiento de CRM | Reglas de Identidad, Perfil Unificado y despliegue de Profile Engagements & Insights en Salesforce CRM. |
| **Ejercicio 5** | Segmentación Avanzada | Creación y refinamiento de audiencias unificadas en el Visual Segment Builder. |
| **Ejercicio 6** | Activación y Flujos | Activación de segmentos hacia canales de destino y flujos de campañas de marketing. |
