# Salesforce Data 360 & Agentforce Interactive Workshop 🚀

¡Bienvenido al taller interactivo de **Salesforce Data 360 y Agentforce**! Este proyecto contiene la guía práctica, el entorno navegable y la documentación paso a paso estructurada para aprender a unificar perfiles, construir segmentos con IA generativa y orquestar campañas omnicanal.

---

## 📋 Resumen del Taller

Este taller está diseñado para guiar a usuarios, consultores y desarrolladores a través de la suite de datos e IA de Salesforce. A lo largo de la experiencia práctica aprenderás a:

- **Unificación de Datos:** Modelar y conectar orígenes de datos en el Data Engine.
- **Enriquecimiento en CRM:** Integrar métricas como el LTV (*Lifetime Value*) y paneles de *Profile Engagement* en las páginas de registros de Salesforce CRM (Contacts).
- **Segmentación Inteligente:** Crear audiencias avanzadas utilizando lenguaje natural con **Einstein** y **Visual Segment Builder**.
- **Orquestación Omnicanal con Agentforce:** Diseñar flujos estratégicos de campaña (Emails y SMS) conversando con **Agentforce** e integrando las audiencias unificadas en tiempo real.

---

## 🛠️ Estructura del Taller (Ejercicios)

El taller está dividido en módulos prácticos con guías visuales e interactivas:

| Módulo | Nombre | Descripción |
| :--- | :--- | :--- |
| **Ejercicio 3** | **Data Engine & Unificación** | Modelado de datos, Data Spaces y Data Model Objects (DMOs). |
| **Ejercicio 4** | **Enriquecimiento CRM** | Configuración de componentes de Data 360 (Profile Insights y Engagements) en Lightning App Builder. |
| **Ejercicio 5** | **Segmentación con Generative AI** | Creación y refinamiento de audiencias con Einstein sobre `Unified Individual`. |
| **Ejercicio 6** | **Campañas con Agentforce** | Creación del *Campaign Brief*, adición de canales (Email/SMS) y vinculación del *Start Trigger* con Data 360. |

## 🚀 Cómo Ejecutar Localmente

No se requiere ningún servidor complejo o construcción de Node.js pesada. Puedes ejecutar la interfaz del taller directamente:

1. **Clona este repositorio:**
   ```bash
   git clone https://github.com/galanteh/salesforce-data360-workshop.git
   cd salesforce-data360-workshop
   ```

2. **Abre el taller en tu navegador:**
   - Abre directamente el archivo `index.html` en tu navegador de preferencia.
   - O utiliza la extensión **Live Server** de VS Code.
